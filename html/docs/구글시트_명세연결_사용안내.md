# 공지사항 개발 명세와 구글 시트 연결

연결 시트의 `화면요소` 탭에서 화면ID가 `NTC-01`인 행을 읽는다. `DEV-EX-01` 데모 행은 기존대로 보존한다.

## 최초 연결

1. 편집 권한이 있는 Google 계정으로 연결 시트를 연다.
2. 제공된 `공지사항_NTC-01_화면요소_추가용.csv`를 임시 탭으로 가져온다.
3. 임시 탭에서 헤더를 제외한 15개 행을 복사해 기존 `화면요소` 탭 마지막 행 아래에 붙여넣는다. 기존 데이터·헤더를 덮어쓰지 않는다.
4. 화면ID `NTC-01`과 번호 `01`~`15`이 중복 없이 등록되었는지 확인한다.
5. 공지사항 목업의 `명세 새로고침`을 클릭한다. `시트 반영 완료`가 표시되면 연결된 것이다.

## 이후 수정

- 시트의 항목명·요소유형·설명·기본값·필수여부 텍스트를 수정한다.
- HTML 최초 진입 또는 명세 새로고침 시 최신 값을 읽는다. 명세는 기본 1분마다 자동 갱신한다.
- 화면ID와 번호는 목업 설명 번호의 연결 기준이다. 변경 시 번호 연결을 함께 검토한다.
- 시트 수정만으로 명세가 갱신되며 GitHub 재배포는 필요하지 않다. Google 측 데이터 갱신 지연이 있을 수 있다.

## 반영 범위와 오류

번호 / 항목명 / 요소 유형 / 설명 / 기본값 / 필수 여부를 명세 표에 표시한다. 현재 연결은 설명·메타데이터 읽기 전용이다. 검색 입력, 실제 폼 기본값, 옵션, 상태 전환이나 권한 동작을 변경하지 않는다.

공개 읽기가 이미 가능한 데모 시트를 사용한다. 이 작업은 시트 공유 권한을 바꾸지 않는다. 읽기 권한·네트워크 문제, 번호 중복, 필수 열 누락, NTC-01 행 없음은 패널에 안내하고 이전 명세를 유지한다. 시트 셀의 HTML·스크립트는 실행하지 않고 텍스트로 표시한다.

비공개 명세로 전환하는 경우 별도 읽기 권한 연결이 필요하다. 민감한 정보는 공개 목업용 시트에 기입하지 않는다.
