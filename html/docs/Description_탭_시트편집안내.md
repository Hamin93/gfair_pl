# NTC-01 전용 시트 편집

연결 시트: https://docs.google.com/spreadsheets/d/11ta8oBialEa6NBmHdngQXZFjLCD9ouPmQ_GJBAb78RE/edit?gid=214103993

NTC-01 공지사항목록 탭에서 6개 표의 데이터 셀을 편집한다. 화면요소는 개요·항목 정보·정책 설명을, 나머지 표는 옵션·상태 정의·상태 전환·버튼 동작·사용자별 권한을 담당한다. 표 위의 # 구분 제목과 열 제목은 유지한다. 번호로 연결하며 새 행도 같은 형식을 사용한다.

화면의 새로고침 또는 기본 1분 갱신으로 반영된다. 선택 탭과 목업 검색 입력은 유지한다. 읽기 실패·번호 오류 시 이전 명세를 유지한다. 시트 편집은 설명만 변경하며 실제 서비스 옵션·권한·서버 동작을 바꾸지 않는다. 기존 데모·화면요소 탭은 보존되어 있으며 현재 화면은 새 전용 탭만 읽는다.
