# 공지사항 Description 탭 편집

대상은 NTC-01이며, 연결된 Google Sheets의 `화면요소` 탭에서 편집한다.

- A~J 열의 기존 내용과 데모 DEV-EX-01 행은 유지한다.
- F `설명`: 번호별 탭의 화면 구성·상세 설명.
- K `개요설명`: 개요 표의 간략한 설명.
- L `권한`: 역할·조회 범위·허용 작업·제한 조건.
- M `상태`: 선택값과 상태 의미·진입·전환 조건.
- N `처리`: 노출·활성·검증·클릭 후 동작·성공·실패 결과.
- O `예외`: 미구현 범위·협의 사항·오류 처리.

L~O는 한 줄에 `구분: 조건 또는 설명`을 작성하면 상세 탭에서 두 열 표로 표시된다. 줄바꿈은 새 행으로 표시되며 HTML 코드는 실행하지 않는다.

개요는 번호 / 항목명 / 요소 유형 / 설명 / 기본값 / 필수여부의 여섯 열이다. 번호 버튼을 누르면 해당 상세 탭으로 이동한다. 번호 탭과 목업의 붉은 번호는 서로 연결된다. 14·15는 연결 화면의 개발 조건으로 관련 진입 영역에 번호를 표시한다. 현재 역할에서 숨겨진 요소는 표시되지 않는다.

시트 변경 후 상단 `새로고침`을 누르거나 기본 1분 갱신을 기다린다. 현재 탭과 목업 검색 입력은 유지한다. 갱신 실패 시 이전 Description을 유지하고 오류를 표시한다. 실제 서비스의 옵션·권한·상태·저장 동작은 Description 편집만으로 바뀌지 않는다.

번호는 양의 정수이며 NTC-01 안에서 중복되지 않아야 한다. 항목명은 필수다. 미정 정책은 협의 필요로 남기며 승인된 정책처럼 작성하지 않는다.
