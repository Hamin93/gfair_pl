# G-FAIR HTML 화면 소스 v2.0

작업일: 2026.10.08 (한국 시간) / 작성: with

## 열기
`index.html`을 더블클릭하면 브라우저에서 열립니다. 인터넷 연결이나 프로그램 설치가 필요하지 않습니다. 전달할 때는 폴더 전체를 함께 전달하세요. `pages` 폴더의 HTML도 각각 직접 열 수 있습니다.

## 폴더 구조
- `css/common.css`: 모든 화면의 공통 디자인과 반응형 스타일
- `css/navigation.css`: 1·2·3뎁스 메뉴와 현재 위치 스타일
- `include/header.js`: 공통 헤더
- `include/sidebar.js`: 공통 사이드메뉴
- `include/footer.js`: 공통 푸터
- `data/navigation.js`: 사이트맵 메뉴명, 뎁스, 역할별 노출 조건
- `data/screens.js`: 화면별 표·필터·폼·예시 데이터
- `js/app.js`: 목록 → 등록/상세 → 수정 → 목록 흐름과 화면 동작
- `js/workbook.js`: 엑셀 읽기·다운로드
- `vendor`: 외부 접속 없이 사용하는 라이브러리와 라이선스
- `pages`: 73개 화면의 개별 HTML 진입 파일
- `docs`: 메뉴 대응표, 요구사항 원문, 반영 범위, 검수 기록

정적 HTML은 서버 인클루드 없이도 열리도록 `include`의 공통 렌더링 파일을 script 태그로 불러옵니다. 페이지별 헤더·메뉴를 복제하지 않습니다. 서버 개발 시 이 폴더를 JSP/PHP/템플릿 인클루드로 이전할 수 있습니다.

## 메뉴와 화면 흐름
2026.10.08 확인한 공유 스프레드시트의 사이트맵 Lv1/Lv2/Lv3를 기준으로 구성했습니다. 모니터링이 메인입니다.
`상담일지 > 상담일지 현황 > 구매상담일지 / 수출상담일지`, `환경설정 > 만족도설문 관리 > 설문관리 / 응답관리`를 실제 3뎁스로 표시합니다. 최신 시트에서 해외 바이어 아래에 방한관리 3뎁스는 없으므로 임의로 추가하지 않았습니다.
등록·상세·수정·엑셀 업로드·QR 관리·출석·이력은 해당 관리 화면 안의 버튼으로 진입합니다. 사이트맵에 없는 작업 페이지를 사이드 메뉴에 나열하지 않습니다.
관리자는 기업정보 메뉴를 숨기고 참가기업 관리에서 조회합니다. 국내바이어와 통역원에는 기업정보가 표시됩니다. `△` 권한은 열람 예시로 반영하고 실제 운영 권한은 발주처 확정이 필요합니다.

## 구현 범위
이 결과물은 예시 데이터로 검토하는 HTML 프런트엔드입니다. 실제 회원 인증, 서버 저장·자동 동기화, SMS, QR 인증·발급, 홈페이지 DB 연계와 클라우드 운영은 백엔드 연결이 필요합니다. 화면에서 실제 작업 완료로 오해하지 않도록 검토용 표시와 안내를 제공합니다.
상담일지 초안은 기기에 약 30초마다 저장하고 새로고침 시 복원합니다. 일반 관리 데이터는 열린 화면 세션에서만 유지됩니다. 명함 이미지는 현재 실행 중 미리보기이며 OCR은 기술협상에서 제외되어 있습니다.
개인정보 암호화, 접근 통제, 감사로그 보존, 성능·가용성, 법령·표준 인증은 정적 HTML만으로 완료하거나 검증할 수 없습니다. 회원·상담일지·설문 세부 양식, QR 운영절차, 매칭 방식과 승인 주체는 원문의 협의 사항을 유지했습니다.
